**Node 1: why should borrowing imply total loss?** The strongest replacement
account is conservative joint transfer: all contributors together preserve

## Finite-path extension: deferred exact gap

The proposed iteration is invalid for an arbitrary positive contraction:
monotonicity and a metric bound do not give T(a+b) ≤ T(a)+T(b).
For example, on nonnegative scalars T(x)=max(x-1,0)/2 is monotone,
zero-preserving and contractive, yet T(1+1)=1/2 > T(1)+T(1)=0
(an analyst calculation, not a theorem registered in this batch).
A legitimate extension must specify a positive linear (or suitably monotone,
subadditive) operator, prove the remainder tends to zero, control summability
of the geometric bound, and connect a positive iterate to a finite path in the
*same* nonnegative weighted network, including infinite row sums. Positive
output would imply some finite productive-input path, not well-foundedness of
the entire graph. The next bounded cluster should prove the linear bounded
operator estimate before registering any finite-path conclusion. This batch
claims neither that corollary nor a source-to-being conclusion.

**Complete proposed mathematical outcome.** `finitePath` proves the issue's
finite intrinsic-input path conclusion directly, without assuming additive
iteration for an arbitrary contraction. The carrier is explicitly countable;
weights, input and power are nonnegative; power has a common finite upper bound
M; each weight row and weighted-power row is summable; all row sums are at most
a common 0 ≤ q < 1; and P(v) ≤ s(v) + Σ w(v,u)P(u). Product summability is
explicit (not silently inferred); countability and nonnegativity of P retain the
selected profile even though the proof needs less. `Path` is Mathlib's finite
reflexive transitive closure of the positive-weight relation from effect to
contributor. It includes the zero-length case s(v)>0. It has the same intended
orientation as the existing `FiniteCausalPath`; no unproved identification with

Proof: if x has no finite path to positive input then s(x)=0 and every
positive-weight contributor also has no such path. Induction gives
P(x) ≤ q^n M for every n, using termwise comparison of genuinely summable rows
and distribution of a constant across the sum. Geometric decay contradicts
P(x)>0. This establishes a positive weighted-network corollary, with arbitrary
countable branching, cycles and infinite ancestry still permitted. It does not
assert the full Neumann-series inequality or construct an actual infinite
series of operators: those stronger assertions are unnecessary to the requested
finite-path conclusion. Signed cancellation is not an allowed interpretation.

`vanishingTail` proves a second, weaker sufficient profile on successor chains:

contrast, `nonuniformTail` proves that EVERY finite product in the issue's
nonuniform countermodel is bounded below by positive P(n). Thus it fails the
weaker vanishing-tail criterion too; merely counting infinitely many strictly

the swap balance and total; it does not certify real-world realization, ultimate
