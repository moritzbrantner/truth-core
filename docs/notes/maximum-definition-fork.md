# Maximality, greatest represented degree and strict supremacy

The source-shaped `GreatestDegreeCausesAllInGenusReading` and the old open
`MaximumInBeingCausesAllBeingsReading` have different antecedents. The first
requires a greatest represented degree among bearers. The second applies to
**every** bearer with nothing above it under a supplied comparative. A merely
maximal bearer can be incomparable with another bearer, so replacing the first
antecedent by the second strengthens the conditional. Existing attribution
corrections and both original predicates remain unchanged.

The prior `directedMaximalIsGreatest` result concerns a homogeneous partial order
on all beings and also proves uniqueness. Its `HomogeneousScaleReading` and
antisymmetry need more structure than this selected-perfection interface needs.
The new bridge instead takes only a supplied preorder of degrees, active-pair
strict-comparative calibration, local directedness of the selected perfection's
bearers and explicit excluded middle. The represented degrees of each pair have
a common upper degree **attained by a bearer**. Given a maximal m, choose such a
bearer z for m and any x. Maximality rules out m<z. Since m≤z, excluded middle
eliminates the alternative ¬z≤m, so x≤z≤m. The degree of m is greatest. No causal
principle is used to derive this order fact.

This proves only maximal→greatest. Calibration is scoped to active bearers,
while the old `IsMaximumIn` forbids MoreIn from any candidate. No inverse from
greatest to old maximality is claimed for arbitrary inactive candidates. Neither
directedness nor calibration is hidden in the frame or attributed to the source.
In particular no global homogeneous ontology of analogical being, physical
measurement, injective degree function, total comparison or unique bearer is
inferred. Worlds are fixed; the selected respect is arbitrary and is instantiated
as esse only when connecting the old root premise.

A separate checked semantic transport takes this weak maximal-to-greatest
interface and the unchanged greatest-degree causal principle to the EXACT
selected-esse all-merely-maximal causal principle. That transport is marked a
transcription, not a new causal explanation. Both inputs remain visible in the
corpus. A second route to the weak interface uses two independent calibrations
of the SAME primitive superlative, one maximal and one greatest. This is
coextension transport, not philosophical property identity or source identity.

Three named calibration propositions specify whether an independently supplied
Maxime predicate means merely maximal, greatest degree with ties permitted, or
strict supremacy over all distinct bearers. Named coverage is OPEN; structural
coverage under explicit excluded middle leaves a precise remainder negating all
three. A primitive attribution selecting one of two tied bearers supplies a
remaining extension. It challenges this named coverage, not the greatest-degree
causal principle or the root conclusion. Actual negations of the maximal and
strict calibrations plus named coverage yield the greatest calibration; being
insufficient for a particular argument never substitutes for those negations.

The finite incomparable profile uses the existing standard product preorder on
Bool×Bool and assigns (false,true) and (true,false). Both bearers are maximal,
strict comparative calibration holds, but neither is greatest. The source
conditional therefore holds **vacuously**, while the old all-maximal causal
principle fails with the independently empty causal relation. This establishes
non-entailment of the old principle, not falsity of the source conditional.
The tied profile uses Unit degrees for two distinct bearers: local directedness,
strict comparative calibration, maximal calibration and greatest calibration all
hold, yet strict-supremacy calibration fails. Its two explicit greatest witnesses
block any automatic uniqueness inference. These are formal interpretations,
not actual or metaphysically possible ontologies.

The six result types use their exact corpus declaration heads from the outset.
Source claims and all prior Challenges are unchanged. New interpretations are
analyst formulations with attribution deferred. Actual applicability of the
degree representation, directedness and causal input remains OPEN. Their real
root connection is registered, so the computed frontier delta exposes its added
conditional inputs instead of disguising them as premise discharge.
