# Cognitive-meaning definitions and target-relative failure

This analyst batch makes competing meaning accounts independently available as
propositions, rather than asking the owner to choose a sense. Attribution is
deferred. It reuses `Verificationism.Language`, `Frame`, the three existing
verifiability criteria, and the exact existing V2 and V3 results.

## What is already encoded

`VerificationPrinciple F meaningful scope verifiable` is a necessary-only
condition: an independently meaningful sentence in scope must be analytic or
verifiable. It does not say that everything admitted by the criterion has
cognitive significance. The older `StrongVerificationismWithLaws` and
`Ayer1946ExcludesANegation` packages **already** contain full biconditionals;
their existing Challenges and proofs require no correction. In particular,
`Ayer1946Closure.ayer1946ExcludesANegationFails` takes independent meaning
closure and a package identifying meaning with the criterion. It does not
silently instantiate a generic cognitive-meaning premise at a bare criterion.

## Independent definition propositions

Fix the same truth-conditional language, analytic/observation frame, independent
cognitive-meaning predicate and comparison scope throughout a comparison.
`Calibration` is pointwise coextension on that scope. The named options are:

- V1: meaningful iff analytic or conclusively verifiable.
- V2: meaningful iff analytic or weakly verifiable by the unrestricted 1936 test.
- V3: meaningful iff literally meaningful by the 1946 criterion.
- All in scope: every scoped sentence has the independent meaning property.

The last is an analyst comparison option for the supplied truth-conditional
language, not every utterance in every language. V4's expressive membership and
pragmatic adoption remain a different question: they are not silently counted
as interchangeable theories of cognitive meaning. Nor is criterion failure
identified with falsity or absence of truth conditions.

`STMT-MEANING-NAMED-COVERAGE` explicitly says a named option holds. It remains
an **OPEN premise**. `STMT-MEANING-REMAINING-DEFINITION` denies all four on the
same extensional comparison profile and opposes that coverage alone. The
excluded-middle theorem proves structural coverage with this remainder. It is
a logical coverage transcription; it neither establishes named exhaustion nor
claims mutually exclusive philosophical schools. Empty or narrow scope can
make competing calibrations coincide. Philosophical identity and admissibility
are separate from extension and remain open.

Full calibration entails the existing one-way verification principle. The
registered strength relation uses that checked implication; its converse fails
in the explicit control below. The old principle keeps its existing independent
statement identity and source claims.

## Consequential discrimination

The V2 rejection composes the existing
`Ayer1936Trivial.ayer1936CriterionTrivial`. The independent target requirement
supplies an in-scope meaningless content whose negation does not entail some
observation. The old construction admits that content. Full V2 calibration
would make it meaningful, so that calibration fails. The independent exclusion
requirement is essential: an indiscriminate criterion is inadequate for that
demarcation target, not automatically false in every language.

The V3 rejection specializes the existing correctly calibrated package
refutation. It retains independent meaning closure, Church's exact observation
setting and an independently excluded negation. It uses global scope because
the old result's biconditional applies throughout the language. Strong negation
closure is needed at an arbitrary content `y` to obtain meaning of `neg y`;
closure only at already-negated contents does not provide that instance.
This wrapper is explicitly marked an instantiation transcription, not a new
independent proof of Church's construction or any premise's philosophical truth.

The family result composes these rejections, an explicit open not-V1 input, and
the excluded negation to reject all four named accounts. It concludes the
remainder without assuming named coverage. Adding named coverage would make
that package contradictory; it would not establish a preferred philosophical
theory. A joint model and philosophical applicability of all its inputs have
not been supplied. Failure to find such a model is not a refutation.

## Nontrivial remaining classifier

The checked control reuses the existing two-coordinate language and its
observable frame. Let independent meaning be analyticity (true at every world).
The constant tautology is meaningful, while the observed-coordinate content is
not: it is false at a world. That observed content nevertheless passes V1, V2
and V3, by explicit witnesses. Thus this classifier differs in extension from
all four named accounts and satisfies the necessary-only V3 principle.

This is a genuine nontrivial remaining extension and a strictness control, not
a new candidate name attached to a named extension. It does not establish that
analytic-only meaning is philosophically adequate. It is **not** a model of
the entire family-rejection package: its meaning predicate does not have the
strong negation closure used there. No joint-consistency claim is inferred.

## Remaining research

The next substantive question is which independently specified meanings and
demarcation goals deserve consideration, and whether the corresponding inputs
can coexist under one semantic profile. The encoded definitions may now be
conditionally studied without independently settling their warrant first.
Admissibility, named philosophical exhaustion and real cognitive significance
remain explicit research gaps. Historical source authentication remains a
separate deferred question and does not block these conditional results.
