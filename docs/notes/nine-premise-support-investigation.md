## Outcome

The investigation found substantive support for the selected potency and
privation meanings, a useful strict-grounding route to nonmutual dependence,
an explicit separation mechanism for independence, and more narrowly scoped
causal, priority and logical bridges. Each proposed bridge identifies what
would have to be supplied for it to support the exact existing proposition.

These are the nine inputs common to every minimal support in the
[published terminal-only calculation](god-existence-support-formula.md).
They are not nine mandatory premises for every conceivable argument for God,
nor nine propositions that must have disjoint foundations. Direct acceptance
of any intermediate proposition remains available alongside its derivations.

The work adds research notes and attempts to the existing dossiers. It does
not add certified logical edges, change a premise's meaning, or mark any new
premise established. The previous DNF counts remain a snapshot of the unchanged
registered argument graph. The finite checks below concern explicit formal
interpretations; they are not evidence that a metaphysical interpretation is
true.

## Most useful exact additions to the support map

### Potency and privation share a defensible conceptual entry point

Write `A` for being in act, `C` for capacity, `D` for the existing broad
privation, and `P` for potency, always at the same subject, respect and context.
The proposed support package for premise 5 is:

$$
\bigl(D \leftrightarrow (\mathrm{Apt} \land \neg A)\bigr)
\land (C \rightarrow \mathrm{Apt})
\quad\Longrightarrow\quad
C \rightarrow (D \leftrightarrow \neg A).
$$

The line is an unregistered constructive reconstruction with the complete
reasoning in the linked note. Aptitude is suitability to the relevant act, not
actual possession and not a new moral requirement.

For **exactly adopted** `P := C ∧ ¬A`, premises 3 and 5 are constructively
equivalent. For a separately supplied `P`, retain the existing analysis
`P ↔ C ∧ ¬A` as an explicit input. The current corpus already proves the other
direction, premises 3 and 5 jointly implying that analysis. This organizes
shared support without pretending that a bare cycle creates warrant.

The added philosophical support comes from the apt-subject account and
generation/retained-capacity examples, especially Aquinas's
[*De principiis naturae* 1–2](https://www.corpusthomisticum.org/opn.html).
The selected sense is narrower than every use of the word potency, and the
ordinary skill/exercise distinction helps identify which sense is in play.

### Grounding can support nonmutual dependence without a regress argument

The existing result
`92c24bb5-763e-55d0-90b1-ef53d0bd0ab6`,
`TruthCore.Results.Modern.Fine.StrictGroundAcyclic.consistentStrictGroundAcyclic`,
says that for a PLG-consistent `S`, a derivable strict partial ground cannot
be reversed by a derivable weak partial ground. Here strict grounding means
`Derivable S (strictPartial A B)`; weak mutual grounding remains permitted.
The theorem does not identify every metaphysical grounding relation with this
calculus. It supplies a reusable formal reason for nonreversal without
requiring a finite domain or a well-foundedness assumption.

To reach premise 2, one must map each distinct existential-dependence edge to
the relevant derivable strict-grounding formula for the same existence facts.
The proposed composition retains both that map and consistency. It does not
rename counterfactual dependence as grounding, and the imported theorem does
not establish the real-world applicability of the map.

### Independence has a positive witness-producing route

Given a reflexive/transitive requirement relation `R`, required background `N`
and retained being `y`, use the set of everything required by `y` or by `N`.
If `x` is outside that set and the retained state is admissible, that state
witnesses `y` without `x`. This connects an affirmative argument to a concrete
application question: what licenses the retained state as possible?

Here write `D` for `DependsForBeing`. For the existing direct consumer, the
proposed local premise

```text
D(x,y) ∧ ¬D(y,x) → CanBeWithout(y,x)
```

is sufficient with its other two unchanged premises. It need not assert
separability for every unrelated pair. Separately, the existing intermediate
`STMT-NONMUTUAL-DEPENDENCE-SUFFICES-FOR-PRIORITY` remains available for direct
assessment on explanatory grounds without this modal detour.

### Efficient causation has an existing scoped connection

The earlier q.104 investigation already identified the important distinction:
causing a thing's becoming or a particular state is different from causing its
continued being. Fresh selected reading corroborates that result rather than
claiming a new discovery. The additional support map identifies how the
esse-specific dependence premise can feed the existing
`Round2Grounding.esseCauseGroundViaDependence` theorem together with its actual
existence, concreteness and dependence-to-grounding inputs.

The general causal analysis in
[*Summa theologiae* I q.104 a.1](https://www.newadvent.org/summa/1104.htm)
can inform this conditional route. Its theological conclusion that God
conserves creatures cannot serve as a premise for proving God without an
independent justification. Nor does identifying a cause of a quality by itself
identify a cause of the bearer's existence.

## Cumulative assessment

The most immediately supported pair is potency/privation **under the meanings
already adopted**. The strict-grounding connection is the most useful existing
formal resource newly identified for these support tasks. The priority source
provides a coherent explanatory orientation, while the dependence/separability
work shows exactly where additional modal assumptions enter. The esse-specific
causal route preserves the supported respect and a concrete path into existing
root-facing grounding theorems.

These lines can reinforce one another. Their shared concepts and sources are
recorded so they are not double-counted as independent evidence; sharing does
not disqualify them. Direct conceptual acceptance, observed distinctions in
ordinary acquisition and competence, source arguments, and explicit conditional
derivations remain compatible forms of support. None requires a detached proof
tree for every starting proposition.

The assessment would change if a proposed interpretation failed at an actual
consumer, if a real same-sense case defeated a claimed universal, if the
grounding theory's consistency/application failed, or if the proposed retained
state violated the beings' actual identity or required background. Open
application bridges are not presented as defeated merely because they remain
open. Conversely, agreement between reviewers is not proof of premise truth.
