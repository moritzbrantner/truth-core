# Excluded middle, assertion and the remaining coverage boundary

The existing `ExcludedMiddleWithheld` package concerns stage-indexed proof and
assertion markers: asserting an excluded-middle instance requires a marker
for one side; some instance is unasserted somewhere; every instance is
irrefutable. It is derived by an existing result from explicit intuitionist
proof commitments and a separately open assertion-requires-proof input.
Those statements, source claims and frozen proofs are unchanged.

Object-level `ExcludedMiddle` is `∀ p : Prop, p ∨ ¬ p`. It contains no stage,
assertion or known-proof parameter. Without a bridge, holding and asserting
are different targets. No bridge is invented here.

`AllInstancesAsserted Asserts` says every stage asserts every instance. This
is an independent comparison policy, not an adopted norm or source fact.
`NotAllInstancesAsserted` is its exact logical negative. The checked
`WITHHOLDING-IMPLIES-NOT-UNIVERSAL-ASSERTION` projects the existing full
withholding package's explicit unasserted stage/content witness to that
negative. It is marked an instantiation transcription, not an independent
philosophical defense of its premise. The stronger raw source position stays
an explicit premise; it is not replaced by a weaker attributed reading.

## What the marker controls establish

The first exported witness satisfies the encoded withholding package,
object-level excluded middle and failure of universal assertion. Object-level
excluded middle is supplied explicitly. The implementation chooses
no-assertion/no-proof markers; those extra properties are not exported.
The checked constructive irrefutability result is imported rather than
reproved. This demonstrates compatibility of these exact encoded formulas.
It is **not** a classical semantics attributed to intuitionism, a complete
intuitionist model, or a theory of epistemic access.

The second exported witness fails both the full withholding package and
universal assertion. Its implementation uses two stages, asserting every
content with no proof markers at one stage and none at the other; the mixed
stage behavior is not an additional exported property. Thus
refuting the full raw package would not by itself establish the universal
assertion policy either. A logical negative target is needed for that role.

## Exact global complement and endpoint migration

The weaker explicit-denial proposition is `∃ p, ¬ (p ∨ ¬ p)`, not
`¬ ∀ p, p ∨ ¬ p`. Its constructive refutation proves no instance deniable,
not general excluded middle. `STMT-NOT-EXCLUDED-MIDDLE` now records the exact
global logical complement as an independent, unrefuted analyst proposition.
It is not attributed to intuitionism. No proof of its refutation or independent
coverage `EM ∨ ¬EM` is supplied.

The unchanged full withholding position now targets universal assertion. Its
exact negative assertion-policy consequence remains a separate alternative,
so refuting the stronger full package alone cannot defend universal assertion.
Object-level EM retains both the weaker instance-denial and the unrefuted
exact global complement. No proof-known, assertion-to-validity or warrant
mapping is invented as a source fact.

The legacy EM floor retains its existing basis and justification; its
disagreement metadata now also lists the global complement. This is not new
floor approval or a proof of EM. A focused regression reads the actual corpus
records and removes that floor in memory: refuting explicit instance denial
then does **not** close or establish EM, because the global complement remains
unrefuted. The same fixture without that global rival reproduces the unsafe
all-alternatives-refuted path; retaining the legacy floor preserves its
existing authority. Run:

```
python3 -m unittest discover -s scripts -p test_excluded_middle_scope.py
```

The broader finite-rival limitation remains: `defended()` treats a nonempty
list of recorded alternatives as sufficient when every member is refuted,
without requiring an independent coverage result. This focused repair blocks
the concrete false-closure path; it does not introduce a new proof registry or
solve every philosophical coverage question. Conditional definition forks
continue to retain ordinary explicit coverage premises and checked derivations.

The serious intuitionist position remains at full strength, including its
separate proof and assertion commitments. An eventual comparison of valid
rules/proof systems must encode its semantic profile and any mapping to the
stage markers explicitly. No complete census of logics or meaning theories
is claimed by this bounded policy consequence.
