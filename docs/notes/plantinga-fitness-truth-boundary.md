## Exact semantic comparison

An input supplies a true binary value and an action target with that same value.
A belief bit represents that value. `act` follows the represented bit when
polarity is false and reverses it when polarity is true. This is an analyst's
small response rule, not a full psychological semantics of desires. Coupling the
truth value and success target is favorable to a truth/success connection, but
still leaves the polarity bridge indispensable.

The certificate proves:

- Successful action at one input holds exactly when polarity is the XOR of belief
  and target. Every belief map therefore admits a compensating polarity map.
- Conditional on successful action at every input, all-state truthful belief is
  equivalent to universally direct (non-reversing) polarity. This is the positive,
  non-compensating rival control, not merely a misleading-agent construction.
- On an inhabited two-input domain, the identity belief map/direct polarity and
  negated belief map/reversing polarity produce the same entirely successful
  response function. The latter is false at each represented input.
- Every Nat-valued score of those entire response functions is equal. Extensional
  function equality uses approved Mathlib function mathematics; the certificate's
  reported axioms are `propext` and `Quot.sound`.

This is not an opaque bridge transcription: finite response calculation forces
an exact constraint, and dropping direct polarity admits a concrete opposed-truth
control. The certificate retains successful behavior in both rivals and changes
polarity together with belief. It does not show false belief possible with the
*same fixed direct polarity*. Nor does it prove every adaptive false belief can
be realized under actual psychological, neurological or evolutionary constraints.

## Philosophical limits and premise comparison

No naturalism, evolution, probability distribution, selection dynamics, warrant,
defeater or theology predicate occurs. Existence of both controls neither makes
them equally probable nor establishes that reliability is low or inscrutable.
That leap requires independently defended priors/likelihoods or another argument.
Likewise, success is stipulated target matching, not independently certified
survival or reproduction. All-false concerns one represented binary content at
each input, not every human belief, logical truth or entire worldview.

The result excludes an unconditional inference from success alone to exact truth
within this mechanism. A stronger rival survives by defending Direct or another
truth-connected response mechanism; a probabilistic bridge might support weaker
reliability without Direct. No metaphysical theory wins merely by matching these
controls. Intended and actual root-path premise delta: **no change**. No root
premise was discharged; the missing empirical and epistemic bridges remain open.
