# Competing operational definitions of objective truth

This source-free analyst batch implements part of the owner's competing-definition
audit. The older `DEF-OBJECTIVE-TRUTH` gloss says truth independent of attitudes,
and the existing comparison signature retains it as an independent predicate.
The definition record now links that exact primitive projection, while the
source claims and their frozen Challenges are preserved. No operational account
below is attributed to their authors or adopted as all philosophical objectivity.

## Explicit alternatives and coverage

Fix sentence contents, a supplied family of attitude profiles, one actual
profile, truth evaluations over those profiles, and an independent `objective`
classifier. Content and non-attitude facts are intended to stay fixed across the
profiles. That intended applicability is an open interpretation bridge.

The three independent definition propositions are pointwise calibrations:

1. **Actual-stable:** objective iff actually true and truth status is stable
   across the supplied profiles.
2. **Invariance only:** objective iff truth status is stable, even if false.
3. **Actual truth only:** objective iff true at the actual profile, without
   requiring stability.

`STMT-OBJECTIVE-TRUTH-NAMED-DEFINITIONS-COVER` says at least one of those
calibrations describes the current classifier. It remains an **open premise**.
`STMT-OBJECTIVE-TRUTH-ADDITIONAL-DEFINITION` says none describes it, under the
same profile and extensional comparison class. It is an alternative to named
coverage, not automatically to every target claim. In the control, the remaining
classifier still has a truth component.

Excluded middle proves coverage **with** that remainder. Named coverage and
negations of the latter two accounts conditionally give the actual-stable
account. This logical elimination is a transcription of the explicit disjunction;
it does not independently warrant any eliminated branch. An unexamined option
therefore has an exact proposition and comparison scope. Failure to find an
account is not evidence that the named class is exhaustive.

Calibration concerns coextension of classifiers, not identity of properties or
philosophical equivalence. Robust versus minimal truth, representation,
explanatory work, causal independence and justified recognition are separate
questions. The operational profile construction does not settle them.

## The weakest bridge and the external-evil result

`STMT-OBJECTIVE-TRUTH-HAS-TRUTH-COMPONENT` is only
`∀ s, objective s → holds actual s`. Actual-stable calibration entails it, but
both actual-only and a genuine remaining account can satisfy it as well. Its
verified strength registration keeps the stronger complete account out of the
external-evil proof.

`POE-EXTERNAL-TRUTH-TO-OBJECTIVE-BRIDGE` imports the exact existing
`POE-EXTERNAL-PREMISE-VS-EMOTIVISM` theorem and retains all four of its
semantic/classification premises. The old theorem gives that the selected
moral-evil premise is not true. The weak truth-component premise then rules out
its satisfying the supplied objective predicate. It does not rule out
suffering, affective protest or target-internal critique.

The omission control preserves **all four old hypotheses** while an
invariance-only classifier calls the selected stably false moral content
objective. The weak truth component is explicitly false. Thus the older
four-premise package alone cannot supply the extra objective conclusion for
an arbitrary independent classifier. This is a model of that exact premise
package, not of the proponent's complete worldview; a separately stated denial
of objective moral truths is not among those four inputs.

## Nonvacuous semantic controls

In the baseline finite table, there are four contents: stable true, stable
false, actually true but profile-variable, and actually false but variable.
The actual profile and the other profile differ only for the last two rows.

| Classifier | Selected contents |
|---|---|
| Actual-stable | stable true |
| Invariance only | stable true and stable false |
| Actual truth only | stable true and actually-true variable |
| Remaining singleton | actually-true variable only |

The remaining singleton has an actually different extension, not merely a new
candidate name. These are countermodels within the broad class of supplied
binary classifiers; their philosophical admissibility is not established.
A separate, nontrivial overlap profile has both actual truth and actual falsity
while all three calibrations coincide. Hence they are not asserted exclusive.

The finite controls retain the advertised properties in their bound conclusion;
no fact is inferred merely from a hidden model's incidental implementation.
