# Bounded cross-argument research experiments (#953)

**Status:** research agenda and registered-evidence discovery, **not** a new
theorem, premise, adequacy criterion, or certification. No change to the root
frontier is claimed. The experiment cards below were checked against the
existing argument, result, attempt, Lean-import and dossier records; they do
not replace source reading, Lean type checking, or Comparator verification.

## Discovery: the small first slice

`scripts/corpus.py bridge-experiments` reads existing attempts, result records,
the full premise bundles of their arguments, and actual direct Lean Solution
imports. Its input is **one result and one explicit Lean profile module**:

```bash
python3 scripts/corpus.py bridge-experiments ULTIMATE-ADEQUACY-COMPARISON \
  --profile-module TruthCore.Explanation.UltimateAdequacy
python3 scripts/corpus.py bridge-experiments ULTIMATE-ADEQUACY-COMPARISON \
  --profile-module TruthCore.Explanation.UltimateAdequacy --json
```

At the implementation snapshot the anchor appeared in **six** attempt evidence
lists, but only **one** surviving experiment had (a) an unresolved recorded
blocker, (b) both result conclusions in the attempt's explicit statement focus,
(c) a direct import of the source Solution, and (d) the selected profile module
in both Solution import closures: `ATTEMPT-JOINT-COOPERATION-744`.

This matters: `ATTEMPT-NECESSARY-BEING-INTEGRATION-786` cites the #735 result
and has consumer imports, but its statement focus does **not** include
`STMT-ULTIMATE-ADEQUACY-COMPARISON`. The integration question is about a
fact-level reason being an actual *existential support*, not the same #735
scenario-space test. A co-mention or an imported type is **not** a license to
join those interpretations. The command excludes this case in the #735
profile slice rather than ranking its root-facing premise above #744.

The calculated score ranks **which bounded investigation to read first**, not
probability, truth, entailment, or value of a worldview. It values root-facing
open focus, a blocked attempt, actual import reuse, and explicitly named
same-profile control hints. Results without a named control are still
investigable; absent search results never refute an argument. Source/witness
fields, if declared on both records, must match exactly. For records lacking
such metadata, **a reviewer must still check full theorem types and the same
fixed interpretation**. An import does not itself establish witness identity.

## Priority 1: productive explanation versus mere joint sufficiency

**Existing registered evidence:** `ULTIMATE-ADEQUACY-COMPARISON` (#735),
`JOINT-COOPERATION-CERTIFICATE` (#744), and their actual direct Solution import.
Both arguments have empty recorded premise bundles, but that only describes
their formal certificate types. The *philosophical* productive/existence
bridge is nowhere certified by those certificates.

**Exact experimental profile:** start from
`TruthCore.Explanation.UltimateAdequacy.exercise` / `groups` / `intrinsic`:
`Nat` event and bearer candidates, `Nat` group records, the fixed target
event **2**, `Bool × Bool` scenarios, actual `(true,true)`, all events
actually occurring, and the existing one Unit context. These are scenario
states, **not** modal worlds. Do not replace a contributor group with a new
substance or silently switch from `Supply` to ontic explanation.

The smallest proposed test is:

1. Hold the #735 `.plural` exercise data fixed. Separate the *observed*
   `jointlySufficient`/`Supply` and both contributors' indispensability from
   a proposed new **productive** reading of the same actual effect. The
   productive predicate is **not** given by the existing `Exercise` record.
   Any proposed bridge must state its direction and additional premises.
2. Construct a **same-record negative interpretation** for a merely regular
   or jointly stipulated law, and a positive productive interpretation,
   changing only the proposed semantic bridge, not the occurrence table,
   group, target, world policy, or participants. If the proposed adequacy
   predicate is definable solely from the retained data, show the definition;
   otherwise record exactly which independent premise is needed.
3. Test the **strongest plural reply**: two independent intrinsically
   contributing sources with a real joint law. Under #735, actual supply
   and relative indispensability coexist with **no** least graph source.
   A productive-applicability bridge alone therefore does not yield unity.
   A separate source-unity premise must survive the plural control.
4. Run positive/omission comparisons within the *same model family*: `.single`
   supplies and has a least source; `.plural` supplies but lacks a least;
   `.branch` has a least but not target-2 Supply; `.chain` has neither.
   These are four **different** interpretations under one fixed type/profile,
   never one combined witness. The #744 `fit`, `single`, `guided`,
   `FitRival` and `VariationRival` examples are useful *separate* controls,
   but may not be transplanted into #735 without a typed map and its proof.
5. Re-test the same causal standard symmetrically for **one** and **plural**
   sources. #744 shows that banning the brute-coincidence branch does not
   discriminate source count, and excluding fit among always-present
   contributors builds in an at-most-one restriction. Record countermodels
   to overstrong bridges before proposing further Lean obligations.

**Success:** either a clearly typed candidate bridge with explicit open
premises, a decisive matched counterinterpretation, or a demonstrated
**non-discriminator** that closes this research proposal as rejected. It is
*not* success to re-prove #735/#744, merely rename `Supply` as "adequacy",
or claim that a formal model is metaphysically possible.

**Best rival to preserve:** independently existing necessary sources with
their own intrinsic powers and a jointly obtaining law. Their coordination
need not be a further produced *thing*, but the account owes a defensible
explanation of the law's actual applicability. The unity advocate likewise
owes the per se/productive bridge, applied equally to single-source laws.

## Priority 2, gated: fact-level reasons to concrete existential support

**Existing evidence:** `ATTEMPT-NECESSARY-BEING-INTEGRATION-786`,
`NECESSARY-CONCRETE-FROM-ACTUAL-GROUNDED`, `NECESSARY-ROOT-TRILEMMA`,
`EXPLANATORY-ADEQUACY-COMPARISON` and the exact open
`STMT-EVERY-CONTINGENT-GROUNDED-AT` premise.

**Question:** in **one specified** bearer/world/actual-grounding profile,
does an actual fact-level sufficient reason warrant an actual concrete
supporter of a contingent bearer? An explanation *of a proposition* need
not name or ground an actual bearer. The #786 attempt explicitly records
the missing bridge and an undefeated well-foundedness assumption.

**Gate before any theorem claim:** select one actual world, bearer population,
concreteness and presence policy, and the mapping from reason facts into
same-world grounding/support. Do not compose separate ontic, graph and
fact-model controls as though they were one witness. Try both an intrinsic
necessary ground and an inertial/brute contingent-root interpretation **under
the same policy**. Existing
`Q3A4-ESSE-CAUSE-OMISSION-MODELS` is a lead for an omission test, not
a portable refutation. If no matched typing is possible, report a **profile
boundary**, not a new result. This experiment stays outside the #735 CLI
slice until that bridge is explicit.

## Priority 3, lower value now: local law versus selected actual history

**Existing evidence:** `HISTORY-SELECTION-CERTIFICATE`,
`ULTIMATE-EXPLANATION-SELECTION`, `ATTEMPT-ACTUAL-WORLD-GAP-751`.
The existing comparison already distinguishes locally satisfied rules from
global selection; a source-free unique global-solution construction is a
positive mathematical counterweight, not productive actuality. Re-running
constant-vector or token-copy controls without an independently motivated
selection relation is likely to repackage settled work. Revisit only with
a **new pinned serious rival** and one typed, same-world hypothesis that
discriminates it; an absence of a proof is not evidence against the rival.
