# Composer attribution and temporal scope

The existing `STMT-COMPOSER-IS-EFFICIENT-CAUSE-OF-COMPOSITE` deliberately says
nothing about when its efficient cause acts. Its existing SCG I.18 attribution
remains independent. The earlier absence of a time-neutral relation was an
encoding gap, not a reason to defer conditional investigation. The analyst frame
now supplies that independent attribution; selecting a temporal interpretation
requires a separate proposition.

The selected-time definition identifies the attribution with activity at one
supplied evaluation time. The existential-time definition identifies it with
activity at some time in the admitted domain, for the same beings and respect.
The latter is a temporal production reading, not all time-neutral causation:
atemporal accounts are not reduced to a time-indexed relation. Neither naming
these definitions nor proving their structural disjunction establishes that
they exhaust philosophical accounts. Named coverage is OPEN, and `Other`
explicitly negates both calibrations. It challenges coverage, not the original
composer attribution or the composite conclusion. The coverage certificate
uses explicit excluded middle and permits overlap.

The canonical `EfficientlyCausesIn` vocabulary is evaluated here and now.
`TemporalActualization` already distinguishes event tokens, clocks and causal
edges but does not provide efficient causal activity indexed by time. The new
index therefore fills this specific missing interface rather than identifying
ordinary succession or an event projection with efficient causation. The frame
has one fixed semantic profile/world; it assumes no clock order, causal priority,
asymmetry or well-foundedness. Only the supplied beings, respects and admitted
times are quantified. Real applicability remains OPEN.

Two checked routes connect back to the exact prior argument:

- Temporal production plus persistence restricted to actual uniting tuples gives
  the existing present-time efficient-composer premise. The persistence premise
  is explicit and permits a different respect at the selected time; the stronger
  universal same-respect persistence proposition is registered separately.
- Temporal production plus no self-efficient-causing at **every** admitted time
  gives the original distinct-uniter conclusion without any persistence premise.
  This imports `CompositeUnitingCauseFromUnion.compositeHasAUnitingCause`,
  instantiating its efficient relation by existential-time activity. Its other
  three premises (two components, diverse union and causing esse) remain exactly
  the prior independent inputs. No efficient-to-esse identity is introduced.

The all-time self-causation ban strengthens the selected-time ban. The stronger
input is needed for the historical route because its witness can lie outside
the selected time. The checked past-self interpretation satisfies all other
composition inputs, a present-time ban and an actual composite, yet fails the
same distinct-uniter conclusion. This is a formal control, not an actual or
metaphysically possible self-producing thing. A departed-builder interpretation
has distinct efficient production at another admitted time and no present
activity, satisfies the all-time ban, and refutes any automatic historical-to-
present transfer. A currently active interpretation permits both calibrations.
Another control satisfies restricted persistence while unrelated efficient
activity ceases, separating it from universal persistence. The remainder assigns
an unspecified attribution without temporal activity; it witnesses failure of
both named calibrations without asserting that this is a positive adequate
account of atemporal causation.

Calibration transport, persistence transport, strength projections, coverage and
named elimination are marked transcriptions/instantiations. The historical
composition result reuses the checked substantive uniter argument and derives
distinctness at the activity witness; neither it nor any model establishes its
framework inputs. Named elimination requires coverage **and** actual negation of
the selected-time definition; finding that a definition fails alone never proves
the other.

The initial draft Challenges used convenient expanded or alias heads. The binding
checker requires the corpus's exact named declaration heads, while Comparator
retains the frozen Challenge syntax. Those drafts remain unchanged with their
original Solutions. Separate `Bound` siblings give exact corpus heads and compose
the unchanged draft theorems; no premise, target or semantic strength changed.
A first model proof's existential `choose_spec` introduced Classical.choice;
ordinary propositional existential elimination replaces it. Final certificates
permit zero axioms.

Source attribution is deferred for the new analyst interpretations. Existing
source claims and frozen prior Challenges are unchanged. Remaining work is to
investigate actual applicability and serious positive atemporal/sustaining
accounts when they discriminate the case, rather than treating the supplied
finite controls as an exhaustive theory census. The computed frontier comparison
records the extra visible conditional inputs; none is a premise discharge.
