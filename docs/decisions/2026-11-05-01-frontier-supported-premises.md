**Supported is its own frontier category.** The frontier and `frontier-diff` report open premises as *bare*, *supported* (only a `supports` relation, with a recorded gap note) and *stated* (a stating claim). A relocation counts as progress only if it adds no bare premise; supported premises stay visible in their own column, so the gap is not hidden. Refines the 2026-10-24 relocation rule.
