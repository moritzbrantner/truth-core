A theory is a set of propositions and arguments plus an **answer map** (question → proposition or "unexplained"). Results are presented as **counts plus prose**, never an aggregate score. Historical findings carry **no certainty numbers**; competing theories are investigated instead. They are sourced from truth-core's own witnesses (git, `web_snapshot`, `media_span`). historical-source-atlas is used only under invariant 19's exception: for a concrete node that is blocked without it, pinned like a source.
