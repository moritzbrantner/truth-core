Adopt the Lean module system repository-wide, converting bottom-up in topological waves (a module can import only modules), starting with the cones under the largest hubs, one quickly merged PR per wave generated by the checked-in `scripts/convert_to_module.py`, each with a full build, the pilot's verification, bind-check, corpus check and unit tests, and measured rebuild savings. Every converted file uses `@[expose] public section`, so names, unfolding and NanoDa root lists stay unchanged; declarations are not made private by default. Challenges stay ordinary (non-module) files with their frozen text untouched. New Solutions and vocabulary files are created as modules. Generated aggregators stay ordinary files until `root_imports.py` emits module aggregators for fully converted areas.
